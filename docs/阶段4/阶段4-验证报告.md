## 1 本批改动摘要

1. **导出/导入**（`services/data-io.service.ts` + `pages/data-manage`）：
   - 导出读全量（含墓碑）写 JSON 到 `USER_DATA_PATH`，用 `wx.shareFileMessage` 分享；
   - 导入选文件 → 结构校验 → 二次确认 → 整体覆盖；校验失败不写入任何数据。
2. **隐私合规**（`utils/privacy.ts` + 三个合规页）：
   - 按基础库版本判定：2.32.3+ 调用 `wx.requirePrivacyAuthorize`；2.30.0～2.32.2 弹窗说明并阻断图片能力；
   - 隐私指引/用户协议/关于页独立可访问，均从「我的」入口进入；
   - 隐私检查仅在添加凭证图片前触发，**不阻塞首屏记账**。
3. **云同步可插拔**（`services/sync-merge.service.ts` + `cloud-sync.service.ts` + 分包设置页）：
   - 默认关闭，关闭时为空操作；
   - 后写为准（updatedAtMs 优先、ISO 回退）+ 墓碑同步 + 时间相等本地优先 + 同 `_id` 去重；
   - 失败保留本地真源，不产生重复记录。
4. **云函数**（`cloudfunctions/sync`）：服务端按 openid 隔离执行同样合并策略，含部署说明文档。
5. **「我的」页**：接上分类/预算/数据/同步/合规全部入口。
6. **单测**：新增 3 个测试文件，总计 13 套件 / 120 用例。

## 4 本阶段修复/决策

1. **导出必须含墓碑**：`buildExportFromStorage` 用 `readAllRecords`（含墓碑）而非 `loadRecords`（过滤），否则导出丢删除痕迹、云同步会复活已删记录。已加单测锁定。
2. **时间字段差异统一**：只有 BillRecord 有 `updatedAtMs`，Account/Budget 只有 ISO。合并策略用 `getUpdatedMs` 提取器统一，而非强制类型假设。
3. **云函数"先删后写"**：服务端整体替换集合，保证同 `_id` 唯一无重复；客户端失败保留本地真源。大数据量（>1000 条）分批优化列后续。
4. **隐私不阻塞**：隐私弹窗只在图片能力前触发，首屏记账完全不受影响；低版本走"说明 + 阻断该能力 + 引导升级"，不调用不存在的接口。
5. **游客模式限制**：云开发需真实 AppID，README 与部署说明已明确 `touristappid` 必须替换。

## 5 已知限制

- 云同步真机环境（云开发环境 ID、集合权限、云函数部署）需用户按部署说明实操验证，本环境无法代跑。
- 图片凭证仅存本地临时路径，未上传云端；换机后需重新添加。
- 云函数单次同步受时长限制，>1000 条记录建议分批。
- 导入覆盖后本地数据被整体替换（已二次确认 + 校验失败回滚保护）。
