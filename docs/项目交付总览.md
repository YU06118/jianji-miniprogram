## 2 已实现能力

- **记账**：收支切换、金额键盘（整数≤9位/小数≤2位）、分类网格、日期备注、凭证图片（≤3张、≤200KB/张）。
- **列表**：按日分组吸顶、月份切换、下拉刷新、上拉分页（20条/页）、增删动效。
- **统计**：概览数字滚动、环形分类占比、6月趋势柱图、预算进度三色。
- **设置**：分类增删改排序、预算设置、导出导入 JSON、隐私指引/用户协议。
- **数据**：软删除墓碑（防同步复活）、导入校验失败整体回滚、时间相等本地优先的合并策略。
- **云同步（可选）**：默认关闭、probe 真实增量、upsert 写入、按 openid 隔离、失败保留本地真源。

## 4 关键设计约束（已落实）

1. 金额全程整数分运算，禁止浮点（`formatYuan` 整除取余、`parseAmountToCents`）。
2. 软删除用墓碑，写操作基于全量读取，绝不整体覆盖丢墓碑。
3. 色值唯一来源 `theme.wxss`；TS 侧业务色值集中 `utils/tokens.ts`。
4. 隐私接口按基础库 2.32.3 判定，低版本降级，不阻塞首屏记账。
5. Canvas 2D 需基础库 2.9.0+，项目最低 2.30.0 覆盖；dpr 适配 + view 降级。
6. rAF 统一防御式封装（`utils/raf.ts`），数字动画用 generation token 防并发。
7. 云同步默认为关，本地 Storage 为唯一真源，失败不产生重复记录。
