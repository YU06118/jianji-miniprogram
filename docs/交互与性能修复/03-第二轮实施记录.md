## A. 自绘日期滚轮 date-wheel

- 新组件 `components/date-wheel/`：底部弹层（overlay 面板，translateY 过渡），年/月/日三列 `scroll-view`（`scroll-with-animation`），行高 36px（`calc(--sp-7 + --sp-1)`），首尾各 2 项占位使首尾可滚到视口内。
- 滚动停止 160ms 防抖吸附最近项；年/月变化重算日列（复用 `utils/date` 的 `daysInMonth`，闰年/大小月），越界日收拢到月末；下限 2015-01-01、上限今天（created 时计算，逻辑层写死）。
- 操作条「取消 / 今天 / 确定」：确定回写 `change{value}`；取消/遮罩关闭不写值（`close`）；今天立即选中并关闭。三列定时器按列管理，`detached` 全清。
- `record-editor`：移除原生 picker，日期**整行可点**（44px 热区 + 按压反馈）唤起弹层；「今天」按钮 catch:tap 防冒泡。

## B. tabBar 按压反馈

- `hover-start-time="0"` + `hover-stay-time="160"`（按下即出、抬起保留 160ms）。
- 叠加 touch 兜底：`pressedIndex` 驱动 `tabbar__item--pressed`（上浮 1px + opacity 0.85 + 图标 scale 0.92），不依赖平台 hover 差异。
- 点已选中 tab 也播按压（onTap 的 return 只阻止重复切页）；指示条按压时 0.9 透明度联动，松开恢复。

## C. 显式 pressed 统一（修"只有第一次有效"）

6 处 hover-class 全部改为「显式 pressed 状态 + touch 事件 + 120ms 可清理回弹定时器」：
`glass-button`（disabled/loading 无按压不闪）、`glass-cell`、`nav-bar`（行为零改动）、`amount-pad`（pressedKey 逐键）、`record-editor` 今天按钮、tabBar（见 B）。`variant/loading/disabled` 变化不打断按压态。三个组件 ts 补 `export {}` 模块化（修复顶层常量跨文件冲突）。
