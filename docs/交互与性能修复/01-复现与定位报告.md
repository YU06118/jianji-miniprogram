## 1. tabBar 按压反馈与切换动画

**定位**：`custom-tab-bar/index.ts:23-27`（onTap 直接 `wx.switchTab`）；`index.wxss:40-42`（仅 `:active` 的 scale）；`index.wxss:60-67`（指示条为每个 item 的 `::after`，无过渡）。

**成因**：
1. `:active` 依赖触摸态，真机（尤其 Android WebView）触发不稳定——小程序惯例用 `hover-class`；
2. 指示条是**每个 item 各自的 `::after`**，选中切换时本质是"A 的 ::after 消失、B 的 ::after 出现"，两个独立元素之间 CSS transition 无法产生"滑动"→ 瞬移；
3. `wx.switchTab` 无系统转场，页面 `onShow` 也无入场动画 → 内容硬切。

**改法**：`hover-class` 按压态（`hover-stay-time="120"`，scale(0.92) + 上浮 1px + 透明度 0.85）；指示条改为 tabbar 容器层的**独立 view**，按 `selected × item 宽度` 计算 `translateX`，200ms（`--dur-short`）缓动；图标颜色/缩放 120–200ms 过渡；三个 tab 页 `onShow` 播一次 12px 上移+淡入（320ms = `--dur-medium`），用标记位跳过同页重复触发。

**影响**：custom-tab-bar 三件套 + index/stats/mine。

## 2. 页面间硬切无转场

**定位**：全部 13 页 `navigationStyle: custom`（app.json:24），无任何转场代码；`navigateTo` 后内容直接出现。

**成因**：从未实现页面级转场；小程序也不提供原生页面转场 API。

**改法**：抽 `utils/page-transition.ts` + app.wxss 通用动画类——二级页进入「从右 12px 推入 + 淡入」320ms，返回前播反向 200ms（`--dur-short`）再 `navigateBack`；tab 间仅淡入、无横向位移。只动 transform/opacity；`onHide`/`onUnload` 清理定时器（复用 record-editor 的 `_exitTimer` + `onUnload` 清理模式——BUG-Q6-01 同款防多退一层）。时长全部走现有 token，不新造数值。

**影响**：13 页（record-editor 已有进出动画，接入统一规范）。

## 3. 记账页内置小键盘

**定位**：`record-editor/index.wxml:78-81`（editor-footer 内 glass-button + `<amount-pad show>`）；`index.ts:16-17,30,50,72,79-80,102-103`（keypad 状态链）；`index.json:7`。

**成因**：自绘 `amount-pad` fixed 底部占半屏（wxss:221-229），逐键 `pressKey` 驱动，与系统键盘两套输入逻辑。

**改法**：移除 record-editor 对 amount-pad/keypad 的引用，改原生 `<input type="digit" cursor-spacing="24">`；输入校验复用 `utils/money.ts` 的 `sanitizeAmountInput`（已有：白名单数字+单小数点、两位小数、9 位整数；粘贴非法返回 null → 提示并截断）；**需按需求补一条规则：首位不得出现多个 0**（现有正则允许 "00.5"，将改为输入层拦截 + 单测）；空/0 保存置灰；仅在失焦时格式化为两位小数、聚焦还原可编辑原值（不逐键格式化 → 光标不跳）；键盘弹起用 `bindkeyboardheightchange` 自算 footer 上移，保存按钮跟随。金额大字区跟随输入实时更新。

**⚠ 修正需求前提**：`utils/keypad.ts` 与 `components/amount-pad` **不能清理**——`budget-manage/index.ts:12,33,67-82` 与 `budget-manage/index.wxml:33`（预算编辑键盘）仍在引用。仅 record-editor 移除引用，keypad 及其单测保留。

**影响**：record-editor 三件套；budget-manage 不动。

## 4. 日期选不了以前的日期

**定位**：`record-editor/index.wxml:51-53`（`<picker mode="date" value="{{date}}">`，无 start/end）；`index.ts:110-112`（onDateChange 直接 setData，回显正确）。

**复现结论**：代码层面无日期限制（原生 picker 不设 start 即可往前翻）；`date` 初始为 `todayISO8()` 格式合法。**最可能成因是热区与交互**：picker 只包住 `.editor-meta__value` 文本（约 32px 行高内一小段），且无任何"可选历史日期"的视觉提示；开发者工具中 picker 面板表现与真机不一致，需真机复测（需求 §一.2 也要求以真机为准）。

**改法**：`start="2015-01-01"`、`end="{{today}}"`（onLoad 计算，默认不允许未来；如需未来记账再单独放宽）；点击热区扩大到整行；日期行加「今天」快捷入口（点击回 today 并回显）；保存写入 `this.data.date`（现状已正确，加单测锁定）。仅当真机确认原生 picker 损坏，才降级 `picker-view` 自绘（先写复现结论再改）。

**影响**：record-editor。

## 5. 二级页无返回箭头

**影响**：新组件 + 9 页 wxml/ts 微调。

## 6. 导出并分享报错

**定位**：`data-io.service.ts:46-58`（shareExportFile 的 fail 分支统一 `reportError('shareFileMessage', err)`）；`utils/logger.ts:36-40`（reportError 默认文案「操作失败，请重试」，且 toast 14 字截断）。

**成因**：开发者工具不支持 `wx.shareFileMessage`（真机 2.16.1+）；fail 未区分「用户取消 / 环境不支持 / 路径非法」，统一走无信息文案。**需求 §六要求先在真机复测确认失败码**——工具环境的典型 errMsg 为 `shareFileMessage:fail can only be invoked by user TAP gesture` 或 `not supported`，真机 cancel 为 `shareFileMessage:fail cancel`。

**改法**：`shareExportFile` 返回结构化结果 `{status: 'success'|'cancel'|'unsupported'|'error', errMsg}`（console 打 errMsg）；data-manage 按状态分派：cancel 静默；unsupported → `wx.showModal` 明确文案「当前环境不支持直接分享，文件已保存到本地」+ 自动 `wx.setClipboardData` 复制文件路径 + 提供「复制 JSON 到剪贴板」兜底；error → 说明下一步的文案。导出文件名/内容结构/墓碑字段不动。

**影响**：data-io.service.ts + data-manage/index.ts（失败交互用 modal，不加新页面元素）。

## 7. 整体性能

**定位与成因**：
- `pages/index/index.ts:113-129` refresh()：每次都 `queryRecords` 全量两次（`MAX_SAFE_INTEGER` 全量聚合 + 首页），`onShow:92` 每次都 refresh——**无脏标记**，同月无变更也全量跑；
- `index.ts:144-165` onReachBottom：从服务层**重取全部已加载页**再整体 setData groups——非增量；
- `components/chart-donut/index.ts:36-44,64-73`：observers 每次属性变化都重建 rAF 动画链；页面隐藏（`pageLifetimes.hide`）后动画**不停止**，退栈前 rAF 链仍跑（chart-bar 同构）；
- 图片：首页列表无图片（home-record 无 image），凭证图仅编辑/详情页展示且已压缩 ≤200KB——「列表缩略图」项实际不涉及；详情页图片补 `lazy-load`；
- `wx:key` 已用 `_id` ✓；`lazyCodeLoading` 已开 ✓；列表已分页（20/页）✓。

**改法**：index/stats 加数据脏标记（增删改/切月才置位，onShow 同月未变更跳过）；分页只 setData 增量页（`groups` 追加而非整体替换）；图表组件页面隐藏/组件 detached 时取消 rAF 链，切月仅重绘（canvas 节点已复用 ✓）；详情图 lazy-load。**目标与测量**：真机冷启动 <1s（1000 条）、tab 切换 <200ms、列表 ≥50fps——用开发者工具「真机调试 → 性能面板 / 体验评分」+ `wx.getPerformance` 采样，交付时给改前/改后对比（注明机型/数据量/方式）。

**影响**：index.ts、stats.ts、chart-donut、chart-bar、record-detail（lazy-load）。
