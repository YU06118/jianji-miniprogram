## 阶段四：日期选择（修复月列空白 + 未来日期）

### 定位

- `date-wheel/index.wxml:31` 用 `wx:for="{{months}}"` 渲染月列，但 `index.ts` 的 `data` **只声明了 `years` / `days`，从未声明 `months`**——月列数据源为空，这是真实代码缺陷。
- `initFromValue()` 在打开时夹取了 `[2015-01-01, today]`，但 `settle()` 在滚动吸附时**没有夹取上界**，用户可滚到晚于今天的日期并保存。

### 改动

| 文件 | 改动 |
|---|---|
| `components/date-wheel/index.ts` | `data` 补 `months: [1..12]`；`setData` 类型同步；`initFromValue` 与 `settle` 改用统一的 `clampSelectableDate` |
| `utils/date.ts` | 新增 `DateParts` 与 `clampSelectableDate(year, month, day, minYear, max)` 纯函数：下限 2015、上限 max、大小月 / 闰年越界收拢 |
| `utils/__tests__/date.test.ts` | 新增 11 例：2015 下限、闰年 2/29、平年收拢、4/31→30、今月超日、超月超年、上下限恰好可选 |

### 验证步骤与截图位

1. 记一笔 → 点日期行 → 月列应显示 1～12 十二项（改前为空白）。
2. 年列滚到 2015、月列 1、日列 1 可选；再往前滚被夹在 2015-01-01。
3. 当年列停在本年、月列滚到 12 月，应被夹回本月；日列不超过今天。
4. 选 2020-02-29 确定 → 日期行回显；保存 → 详情日期为所选值，不是当天。
5. 点「今天」→ 立即回显今天并关闭弹层。
6. 截图位：月列十二项滚动图、2015-01-01 选中图、所选历史日期保存后的详情页。

## 可复用经验

1. 「保存按钮置灰」要抽成纯函数并在所有影响字段变化时调用，否则分类切换后会留下错误的旧状态。
2. 组件 WXML 引用的 data 字段必须在 TS 侧声明——`{{months}}` 这类漏声明不会报错，只会静默渲染空列。
3. 边界夹取要「初始化 + 滚动」两处共用同一纯函数，否则用户能通过滚动绕过初始化时的限制。
4. 分享失败必须用 errMsg 分类并明确下一步动作；一律「操作失败，请重试」是最差的用户反馈。
5. tab 页 onShow 全量刷新要区分「切 tab」和「从编辑页返回」：用切换时间戳窗口判定，既省开销又不丢新数据。
6. canvas 节点查询一次即可缓存；切月只重绘，不做 SelectorQuery、不重建节点。
