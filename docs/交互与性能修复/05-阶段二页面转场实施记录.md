## 一、定位结论：为什么"硬切"

### 1.1 现状（改前）
10 个二级页根节点常驻 `anim-page-push`，`@keyframes anim-push-in` 为 `translateX(12px)→0` + `opacity 0→1`（320ms）。`exitAndBack()` 由 nav-bar 调用，置 `pageExiting` 触发 `anim-page-exit`（200ms 反向）。

### 1.2 根因（代码级证实）

1. **常驻类在容器不可见时就播完了（主因）**
   `anim-page-push` 是根节点常驻类，页面首次渲染即启动 CSS 动画。小程序 `navigateTo` 时页面容器的呈现与内容渲染不同步——动画 320ms 在用户真正看到页面之前已结束，等到可见时内容已是终态 `opacity:1 / translateX(0)`，观感就是"内容直接出现"＝硬切。这与第三轮 tab 的 `enterFlip` 布尔隔次播是同类"动画与可见时机错位"问题，但机理不同：tab 是类名被移除，这里是时机过早。

2. **退出 timer 无清理**
   `exitAndBack()` 的 `setTimeout(200)` 未保存 id；若退栈发生在动画窗口内，timer 仍持有旧页面实例。虽有栈顶校验防多退一层，但没有清理路径，违反提示词"onHide/onUnload 清理定时器"。

3. **详情页删除绕过退出动画**
   `record-detail.onDelete()` 直接 `setTimeout(() => wx.navigateBack(), 320)`，既不播退出动画，也无 timer 清理与栈顶校验，与统一转场规范不一致。

4. **动画时长 token 一致性尚可**
   320ms / 200ms 分别对齐 `--dur-medium` / `--dur-short`，a/b 双类复用同一 keyframes，这部分无需改。

## 二、改动清单

### 批 1：动画定义（`app.wxss`）

| 改动 | 内容 |
|---|---|
| 移除 | `.anim-page-push` 常驻类 + `anim-push-in` keyframes |
| 新增 | `.anim-page-enter-idle`（`opacity:0`，首帧隐藏） |
| 新增 | `anim-page-enter-kf`（`translateX(12px)→0` + `opacity 0→1`，320ms `--dur-medium` + `--ease-standard`） |
| 新增 | `.anim-page-enter-a` / `.anim-page-enter-b`（内容相同，双类交替保证重播） |
| 调整 | `.anim-page-exit` 移到 enter 类之后，确保与 enter 同时在根节点时 exit 的 animation 覆盖 enter（200ms `--dur-short`，`forwards`，`pointer-events:none`） |

只动 `transform` / `opacity`，时长走 token，不新造数值。

### 批 2：转场逻辑（`utils/page-transition.ts`）

| 导出 | 改动 |
|---|---|
| `playPageEnter(page)` | 新增：页面 `onReady` 调用，`pageEnterSeq` 0→1/1→2/2→1 交替，切 a/b 双类；首帧 idle 隐藏，动画在可见时机启动 |
| `exitAndBack()` | 加 `_exitTimer` 挂页面实例（可清理）；加重入防护（已播则不再起第二个 timer）；保留栈顶校验防多退一层；栈底 `reLaunch` 兜底不变 |
| `clearExitTimer(page)` | 新增：`onUnload` 调用，清 timer 并置 undefined |
| `playTabEnter(page)` | 不变（第三轮 a/b 双类 + 800ms 窗口） |

### 批 3：10 个二级页 WXML + TS

| 页面 | WXML 根节点 | TS |
|---|---|---|
| `pages/about` `terms` `privacy` `category-manage` `budget-manage` `search` `data-manage` `record-detail` `subpackages/cloud/pages/settings` | `anim-page-push` → `{{pageEnterSeq === 1 ? 'anim-page-enter-a' : (pageEnterSeq === 2 ? 'anim-page-enter-b' : 'anim-page-enter-idle')}}` | data 加 `pageEnterSeq: 0`；加 `onReady(){ playPageEnter(this) }`；加 `onUnload(){ clearExitTimer(this) }`；`record-detail.onDelete` 改走 `exitAndBack()` |
| `pages/record-editor` | 不动（自带抽屉动画 `editor-slide-in/out`，已有 `_exitTimer` 清理） | 不动 |

### 批 4：单测（`utils/__tests__/page-transition.test.ts`，新增）
10 例：入场 0→1、1→2/2→1 交替、缺字段兜底；退出栈底 reLaunch、200ms 后返回、手势弹栈不多退、重入防护；timer 清理；tab 窗口判定（第三轮回归）。
