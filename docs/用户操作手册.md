# 简记 · 用户操作手册

> 简记是一款本地优先的个人记账小程序。数据默认只保存在你的手机里，云同步由你自主选择。

## 1 快速开始

1. 用微信开发者工具打开项目根目录，或体验版/正式版小程序。
2. 首次进入首页，点右下角「＋」记第一笔：
   - 选择「支出」或「收入」；
   - 用自定义数字键盘输入金额（最多 9 位整数、2 位小数）；
   - 选择分类，可填日期、备注，最多加 3 张凭证图片；
   - 点「保存」。

## 2 首页（账单）

- 顶部切换月份，右上角进入搜索。
- 概览卡显示本月支出、收入、结余，数字会滚动。
- 账单按天分组，长按某条删除，点击某条进入编辑。
- 上拉加载更多，下拉刷新。
- 删除会保留「删除标记」用于同步，不会在你的列表里显示。

## 3 统计

- 顶部切换月份，右上角「预算设置」。
- 支出构成：环形图显示各分类占比，下方图例列出金额与百分比。
- 近 6 月支出趋势柱图，超阈值柱用红色高亮。
- 预算进度：正常紫色、达到 80% 变橙色、超支变红色，并显示剩余或超支金额。

## 4 我的

| 入口 | 用途 |
|---|---|
| 分类管理 | 新增/改名/上移/删除自定义分类；预设分类不可删除 |
| 预算设置 | 设置本月总预算与各支出分类预算，可清除 |
| 数据管理 | 导出 JSON 备份、导入恢复、进入云同步设置 |
| 云同步 | 默认关闭，可选开启 |
| 隐私指引 / 用户协议 / 关于 | 随时查看 |

## 5 备份与恢复（重要）

- **导出**：我的 → 数据管理 → 导出并分享，生成 `简记备份-YYYYMMDD.json`。请妥善保存，换机或误删后可恢复。
- **导入**：数据管理 → 选择文件导入 → 选备份 JSON → 确认覆盖。
  - 文件结构校验失败时不会写入任何数据；
  - 覆盖前会二次确认，建议先导出当前数据作备份。

## 6 云同步（可选）

默认关闭。关闭时完全不影响记账。

1. 先按 `docs/阶段4/阶段4-云同步部署说明.md` 完成云开发环境、集合、权限与云函数部署。
2. 我的 → 云同步 → 开启 → 关闭开关后仍可正常记账；点「立即同步」手动触发。
3. 同步策略：后写为准、删除标记一并同步、不会产生重复记录；同步失败保留本地数据。
4. 当前图片凭证只存本地，换机后需重新添加。

## 7 常见问题

- **记不了图片？** 添加凭证图片需相册/摄像头权限，拒绝后仍可记账，只是无法附图。低版本微信需升级。
- **看不到某月数据？** 检查顶部月份是否切对；数据按记账日期归档。
- **统计和列表金额对不上？** 统计按当月全量聚合，列表分页只影响显示条数，不影响统计。
- **云同步失败？** 检查云函数是否部署、云开发环境是否正常；失败不会丢本地数据。
