## 0 冲突声明（按 §0.1 优先级规则，冲突优先于其他描述）

| # | 冲突 | 依据 | 取舍 |

| C5 | §3.2「图片/字体一律走云存储或 CDN，禁止 base64 打进包内」与 §4.2「噪点 base64 ≤2 KB」 | 需求自身已把噪点列为例外条款 | 唯一例外：单张噪点 ≤2 KB、全局一份，放在 `app.wxss` 的 `--texture-noise` 变量中；其余资源一律外链 |

## 1 需求与方向理解（复述，≤200 字）

「简记」是单用户、本地优先的轻量记账小程序，目标为「打开即记、一眼看清」：3 秒完成一笔录入，首页一屏看清本月收支。视觉为深紫渐变到近黑的安静底色，以液态玻璃四层材质（渐变底 / 毛玻璃 / 渐变描边高光 / 极淡噪点）统一承载所有界面，动效自然有惯性。工程上要求原生小程序 + TypeScript、金额整数分、基础库 2.30.0、主包 ≤1.5 MB、全站 token 化、可提交审核。交付按 6 阶段推进，每阶段设确认门。

## 2 技术方案

### 2.1 框架与构建

| 项 | 方案 | 理由 |
|---|---|---|
| 框架 | 原生小程序 + TypeScript | 需求默认值；无框架运行时开销，包体积可控 |
| TS 编译 | `tsc` 预编译输出 `miniprogram/**/*.js`，npm script `build:ts`；开发者工具导入编译产物 | 具体编译插件配置项以本地开发者工具版本为准，**阶段 1 验证后定稿**（未确认项，不臆造配置） |
| 包管理 | npm，Node ≥18，构建 npm 生成 `miniprogram_npm` | 需求 §3.1；README 写明构建步骤 |
| 渲染引擎 | 默认 WebView + CSS 动画；不启用 Skyline | 见 C3；与最低基础库 2.30.0 保持一致 |
| 最低基础库 | 2.30.0 | 需求默认值；隐私接口降级见 C1 |

### 2.2 分层架构

```
视图层（WXML/WXSS，组件化，token 驱动）
   ↓ 事件
服务层 services/（record / budget / stats / sync）：业务编排、聚合
   ↓
工具层 utils/（money / date / storage / migration / wxPromise / compat / logger）
   ↓
存储层：本地 Storage（jj: 前缀）为唯一真源；云同步为可插拔观察者
```

- 所有 `wx.*` 异步 API 统一经 `utils/wxPromise.ts` 包装为 Promise，失败统一 `logger` + `wx.showToast`，禁止静默 catch。
- 本地写入即持久化；云同步监听写入事件，关闭时不影响任何 P0 功能。

### 2.3 金额与日期（纯逻辑层，100% 单测覆盖）

- 金额：字符串解析→整数分，禁止浮点。规则：整数部分 ×100 + 小数部分补足两位，**第三位直接截断**（不四舍五入）；拒绝负号、多小数点、超长（>9 位整数）、非数字粘贴。展示层 `formatYuan(cents)` 用整数除法拆分为 `元.角分`。
- 日期：存 `date: 'YYYY-MM-DD'` + `createdAt/updatedAt: ISO 8601 字符串 + epochMs 数字`双字段。所有比较与分组按东八区（`UTC+8`）计算，不依赖设备时区。
- 阶段 1 单测用例清单：跨月（1/31→2/1）、跨年（12/31→1/1）、闰年 2/29、平年 2/28→3/1、月末 31 日→30 日、UTC+8 跨日边界（UTC 16:00 切日）。

### 2.4 图表方案定稿（§3.5 要求阶段 0 定稿）

**选定：canvas 2d 自绘**（`type="2d"`，Canvas 自基础库 2.7.0 支持，2.30.0 完全覆盖）。

| 维度 | canvas 2d 自绘（选定） | echarts-for-weixin（未选） |
|---|---|---|
| 包体积增量 | 0 KB | 核心库数百 KB，与 ≤1.5 MB 主包预算冲突 |
| 深色主题 | token 直接注入，完全可控 | 需改造主题配置 |
| 动画 | requestAnimationFrame 进度驱动，符合 §4.4 | 依赖库动画，帧率不可控 |
| 兼容性 | 2.30.0 覆盖 | 需额外验证 |

环形图用 canvas 圆弧 + 进度动画；柱状图用矩形高度动画；数值滚动由 `number-roller` 组件在 600ms 内用 requestAnimationFrame 更新文本（仅改文本内容，不触发布局属性动画）。

### 2.5 云同步（P1，可插拔）

- 默认关闭；开启时以 `updatedAt` 后写为准，软删除用 `isDeleted` 墓碑同步。
- 云数据库权限：所有集合「仅创建者可读写」，规则 JSON 见 §6.3。
- 冲突处理：同步前拉取远端游标 → 按 `updatedAt` 合并 → 本地写入不覆盖更新的远端记录 → 整体写回。失败保留本地真源，不产生重复记录。

### 2.6 合规

- 隐私指引与用户协议为独立页面（`pages/privacy`、`pages/terms`），在「我的」入口可随时查看。
- 相册/摄像头首次调用前说明授权用途；`wx.requirePrivacyAuthorize` 在 2.32.3+ 按官方流程接入（`wx.getPrivacySetting` 查状态 → `wx.onNeedPrivacyAuthorization` 弹自定玻璃弹窗 → `button open-type="agreePrivacyAuthorization"`；同意回调后再调用隐私接口），**弹窗不阻塞首屏记账**；低版本降级见 C1。
- 不申请位置、麦克风、通讯录等无关权限，不使用需额外资质能力。

### 5.3 动效

| Token | 值 |
|---|---|
| `--dur-micro` / `--dur-short` / `--dur-medium` / `--dur-long` / `--dur-enter` | `120 / 200 / 320 / 480 / 520 ms` |
| `--dur-num` | `600 ms`（数字滚动） |
| `--ease-standard` | `cubic-bezier(0.32,0.72,0,1)` |
| `--ease-emphasis` | `cubic-bezier(0.34,1.56,0.64,1)`（小幅度回弹） |
| `--ease-exit` | `cubic-bezier(0.4,0,1,1)`（退出，与 520ms 进入配 320ms 退出） |
| `--scale-press` | `0.98` |

动画属性红线：仅 `transform` / `opacity`；图表用 canvas requestAnimationFrame；长列表不做 `setData` 高频驱动。

### 5.4 玻璃组件规格（四层）

1. 底层：深紫纵向渐变 + 2～3 个 `radial-gradient` 光斑，transform 极慢漂移。
2. 毛玻璃层：`background: var(--color-glass-fill)` + `backdrop-filter: blur(20px) saturate(180%)` + `-webkit-backdrop-filter`。
3. 边缘层：`::after` 伪元素叠渐变描边 + `inset 0 1px 0 var(--color-glass-highlight)` 顶高光（不用 `border-image`，wxss 支持受限）。
4. 质感层：`--texture-noise` 全局噪点，opacity ≤0.04。

降级：`utils/compat.ts` 用 `wx.getDeviceInfo()`/`wx.getAppBaseInfo()` 判定，根节点加 `glass--fallback`，改用 `--color-glass-fallback` 实色 + 强化描边与阴影。`backdrop-filter` 精确支持矩阵 wxss 无法特性检测，**列为真机验证项**（未确认，不臆断）。

## 6 数据模型与索引建议

### 6.1 集合定义（在需求 §5.4 基础上的审查与补充）

| 集合 | 字段 | 建议补充 / 索引 |
|---|---|---|
| `accounts` | `_id, name, type, icon, color, sortOrder, isDeleted, createdAt, updatedAt` | 增 `builtIn: boolean`（预设/自定义，禁止删除预设但可软删）；索引 `sortOrder`、`isDeleted`；查询恒过滤 `isDeleted=false` |
| `records` | `_id, accountId, type, amountInCents, note, date, images[], createdAt, updatedAt, isDeleted` | 增 `createdAtMs/updatedAtMs`（同步游标数值）；索引 `{date:1,isDeleted:1}`（主查询）、`accountId`、`updatedAtMs`；`amountInCents` 为整数；`images` 存 fileID/本地临时路径，禁 base64 |
| `budgets` | `_id, month, accountId, amountInCents, createdAt, updatedAt` | `accountId: null` 表示总预算；唯一索引 `{month:1,accountId:1}`，写入用 upsert；不设 `isDeleted`（按月覆盖） |
| `settings` | `_id, key, value` | 唯一索引 `key`；`key` 取值如 `syncEnabled`、`schemaVersion` |

### 6.2 本地 Storage 结构

- key 统一 `jj:` 前缀：`jj:accounts` / `jj:records` / `jj:budgets` / `jj:schemaVersion` / `jj:syncCursor`。
- `jj:schemaVersion` 为当前结构版本；启动执行 `migration.ts` 的幂等迁移链，老数据升级不得丢字段。
- 软删除：`isDeleted: true` + `updatedAt`，列表查询过滤，导出保留标记。

### 6.3 云数据库权限规则 JSON（「仅创建者可读写」，可粘贴）

```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

> 云数据库权限规则以控制台「自定义规则」语法为准；阶段 4 部署时按控制台模板复核后粘贴（语法细节未确认项，不臆造）。

### 6.4 索引创建步骤（阶段 4 执行）

1. 云开发控制台 → 数据库 → 新建集合 `accounts/records/budgets/settings`。
2. 各集合 → 索引管理 → 按 §6.1 建索引（唯一索引勾选「唯一」）。
3. 权限设置 → 自定义规则 → 粘贴 §6.3 JSON。

## 7 兼容性风险清单

| # | 风险 | 平台/条件 | 检测方式 | 降级方案 | 状态 |
|---|---|---|---|---|---|
| R1 | 隐私接口缺失 | 基础库 2.30.0～2.32.2 | `wx.canIUse('requirePrivacyAuthorize')` + `getAppBaseInfo().SDKVersion` | 弹窗说明后阻断该能力，P0 本地记账不受影响 | 已确认版本事实 |
