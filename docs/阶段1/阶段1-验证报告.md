## 3 阶段 1 验证中的技术决策

1. **TS 编译方式**：阶段 0 方案写「tsc 预编译输出 JS」，阶段 1 验证后改用微信开发者工具内置 TS 编译插件（`useCompilerPlugins: ["typescript"]`），导入即编译、零构建步骤。命令行 tsc 仅做类型校验。已在 README 说明。
2. **修复 migration 真 bug**：单测发现归一化函数丢弃自定义扩展字段，违反「老数据升级不丢字段」硬约束。已用对象展开保留未知字段，测试通过。
3. **mask 色值 token 化**：`-webkit-mask` 合成语法中的 `#000` 属技术掩码非视觉色值，但为满足「零硬编码」字面标准，抽为 `--color-mask-solid` token。
4. **骨架页面泛型**：miniprogram-api-typings 的 Page/Component 泛型签名与直觉不同，改用类型推断 + 局部接口断言，保持零 any。
