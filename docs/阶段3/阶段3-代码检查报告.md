## 5 缺陷清单

### BUG-01 · "清除预算"写成 0 元预算，统计页出现荒谬进度条目（P2）

- **位置**：`pages/budget-manage/index.ts` `onClear()` 第 99～111 行 → `upsertBudget(this.data.month, item.accountId, 0)`
- **复现**（已验证 S3-5）：
  1. 设置本月总预算 5000 分
  2. 点"清除" → UI 显示"已清除预算"，条目显示"未设置"
  3. 进入统计页 → `hasBudget=true`（因为残留 1 条 0 元预算记录）
  4. 进度条显示"支出 ¥X / ¥0.00、剩余 ¥X"（`ratio=0` 走正常色，`remain=0-spent` 为负、UI 取绝对值）
- **实际结果**：用户明明清除了预算，统计页却冒出一条"预算 0 元"的怪条目
- **期望结果**：清除后 `budgetsOfMonth` 无该记录，统计页 `hasBudget=false` 显示"尚未设置本月预算"
- **判定依据**：UI 文案"清除"/"未设置"/"已清除预算"与 `amountText==='未设置'` 的分支语义一致指向"删除记录"，实现却是写 0
- **影响**：用户可见的错误展示；不阻断记账/图表/预算正向设置，故定 P2
- **修复建议**：
  - 在 `budget.service.ts` 新增 `removeBudget(month, accountId)`：从 `loadBudgets()` 过滤掉对应记录后 `saveBudgets`
  - `onClear()` 改调 `removeBudget`
  - `computeProgress` 增加防御：`b.amountInCents <= 0` 的条目跳过（兼容历史脏数据）
  - 补回归用例：清除后 `getBudget()===null` 且 `computeProgress()` 不含该条目

### OBS-1 · chart-donut 无 canvas 降级视图（观察项）

- `chart-bar` 有完整 view 柱降级（`wx:if="{{!canvasReady}}"` + canvas 常驻隐藏），但 `chart-donut` 只有单个 canvas，节点不可用时 `renderChart()` 直接 return，环图和中心文字都不显示
- 缓解：`pages/stats` 的 `ratios` 文本列表（分类名+金额+百分比）始终渲染，构成文本占比兜底
- 判定：方案 §7 R8 要求"降级为纯 CSS 柱状/文本占比"，文本部分满足，环形视觉在无 canvas 端缺失。真机验证时留意，非阻断

### OBS-2 · 图表几何对负数/异常值无防护（观察项）

- `toDonutSegments` 用 `value/total` 算占比，若 value 为负会产生倒退角度；`toBars` 负值产生负高度
- 当前调用链：`categoryRatios` 金额为非负整数分、`monthlyTrend` 支出非负，实际不会喂入负数
- 判定：防御性缺失但调用链安全，列为后续健壮性改进，非当前缺陷

### OBS-3 · canvas 动画竞态（观察项）

- 两个图表组件都在 `observers` 和 `lifetimes.ready()` 中调用 `renderChart()`，数据频繁变化时会启动多个 rAF 动画循环并行绘制
- 当前触发频率低（月份切换/首次加载），不会造成可见闪烁；阶段 5 真机走查时留意，必要时加 `animationId` 取消上一轮
