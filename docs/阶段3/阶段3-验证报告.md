## 3 关键 API 事实（微信开放文档，2026-11-25 查证）

| 事实 | 说明 |
|---|---|
| canvas `type="2d"` | 基础库 **2.9.0** 起支持（阶段 0 报告写 2.7.0 实为 webgl，此处修正）；项目最低 2.30.0 完全覆盖 |

## 4 本阶段修复/决策

1. **降级死锁修复**：chart-bar 初版用 `wx:if="{{canvasReady}}"` 控制 canvas 节点，初始 false 导致节点不存在 → SelectorQuery 永远查不到 → 永远降级。改为 canvas 常驻 DOM + opacity 控制，降级视图用 `wx:if="{{!canvasReady}}"`。
2. **组件属性名规避保留字**：`chart-bar` 的 `data` property 改名为 `bars`，避免与 WXML 的 `data-*` 语义冲突。
3. **Canvas2D 类型名**：类型包正确名为 `WechatMiniprogram.CanvasRenderingContext.CanvasRenderingContext2D`，非 `Canvas2D`。
4. **rAF 防御式**：两个图表组件均用 typeof 检测 + setTimeout 回退，与 number-roller 一致。
5. **组件兜底色值**：chart-donut / chart-bar 的 properties 默认色值引用 `utils/tokens.ts`，生产 TS 零色值硬编码。
6. **总预算语义**：total 预算汇总全部分类支出；分类预算只汇总本分类；无预算记录的分类不生成进度条目（避免 0/0）。
