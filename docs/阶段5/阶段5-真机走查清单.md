### 1000 条测试数据生成方法（复用导入功能，不改产品代码）

在 PC 上用任意文本编辑器新建一个 `stress-1000.json`，内容按导出格式生成，然后用「我的 → 数据管理 → 导入恢复」灌入。可用以下 Node 脚本生成（Node 18+，无需依赖）：

```js
// gen-stress.js —— 生成 1000 条账单的导入文件
const fs = require('fs');
const accounts = [
  { _id: 'preset-0', name: '餐饮', type: 'expense' },
  { _id: 'preset-1', name: '交通', type: 'expense' },
  { _id: 'preset-6', name: '工资', type: 'income' },
];
const pad = (n) => String(n).padStart(2, '0');
const records = Array.from({ length: 1000 }, (_, i) => {
  const month = Math.floor(i / 100) % 12 + 1;
  const day = i % 28 + 1;
  const acc = accounts[i % accounts.length];
  const now = new Date().toISOString();
  return {
    _id: `stress-${String(i).padStart(4, '0')}`,
    accountId: acc._id,
    type: acc.type,
    amountInCents: (i % 500 + 1) * 100,
    note: `压测 ${i + 1}`,
    date: `2026-${pad(month)}-${pad(day)}`,
    images: [], isDeleted: false,
    createdAt: now, updatedAt: now,
    createdAtMs: Date.now(), updatedAtMs: Date.now(),
  };
});
fs.writeFileSync('stress-1000.json', JSON.stringify({ schemaVersion: 1, accounts, records, budgets: [] }));
```

> 注意：导入会整体覆盖当前数据，请**先在真机上导出备份**再灌入压测数据；走查结束后用备份恢复。该脚本仅用于验收，不属于产品代码，不纳入版本库测试。
